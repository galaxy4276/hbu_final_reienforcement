# 오프라인 강화학습(Offline RL) 실험 결과 보고서: HalfCheetah-v5

## 1. 개요
본 실험은 `HalfCheetah-v5` 환경에서 온라인 학습을 통해 전문가(Expert) 정책을 생성하고, 이를 통해 수집된 정적 데이터셋만을 사용하여 오프라인 강화학습 에이전트를 학습시키는 과정을 다룹니다. 데이터의 양, 알고리즘(BC, CQL, MARWIL), 그리고 하이퍼파라미터 변화가 학습 성능에 미치는 영향을 비교 분석하였습니다.
## 2. 실험 과정 및 환경 설정
### 2.1. 전문가(Expert) 에이전트 생성 (온라인 학습)
* **알고리즘:** PPO (Proximal Policy Optimization)
* **환경:** HalfCheetah-v5
* **네트워크 구조:** \[512, 512, 256], Tanh 활성화 함수
* **학습 결과:** 약 3,800점 대의 점수를 기록하는 Expert 모델 확보.
### 2.2. 오프라인 데이터셋 구축
* **생성 방법:** 학습된 PPO Expert 모델을 로드하여 추론 수행
* **데이터 수집 구성:**
    * **소규모 데이터셋:** 50 에피소드 (실험 ID: `52f86`, `5206a`용)
    * **대규모 데이터셋:** 500 에피소드 (실험 ID: `15ebd`, `a0a60`, `9b3c5`, `1314c`용)
* **관측 전처리:** MeanStdFilter 적용 (Expert와 동일 환경 유지)

### 3.2. 알고리즘 성능 비교 (BC vs CQL vs MARWIL)
오프라인 데이터 50개를 기준으로 실험을 진행했습니다.
![[Pasted image 20251207195804.png]]
* **Behavioral Cloning (BC - `a0a60`):**
    * **결과:** 주황색 라인. 초기에는 점수가 낮으나 스텝이 진행됨에 따라 **선형적(Linear)으로 꾸준히 성능이 향상**되었습니다.
    * **분석:** 단순히 전문가의 행동을 모방하므로 학습이 안정적이나, 성능 향상 속도가 MARWIL에 비해 다소 느린 경향을 보입니다.
* **CQL (Conservative Q-Learning - `5206a`):**
    * **결과:** 하늘색 라인. **학습 실패 (-200점 대).**
    * **분석:** CQL은 Q-function에 대한 보수적 제약을 가하는 알고리즘으로, 일반적으로 많은 데이터가 필요합니다. 본 실험(`5206a`)에서는 **데이터가 50 에피소드로 극히 적었기 때문에** 분포 외(OOD) 행동에 대한 페널티가 과도하게 작용하여 학습이 붕괴된 것으로 판단됩니다.
* **MARWIL (Monotonic Advantage Re-Weighted Imitation Learning - `15ebd`):**
    * **결과:** 분홍색 라인. **가장 빠른 수렴 속도와 높은 최종 성능**을 기록했습니다.
    * **분석:** 전문가 데이터 중 이점(Advantage)이 높은 행동에 가중치를 두어 학습하는 방식을 통해, BC보다 훨씬 효율적으로 Expert 수준(3,000점 이상)에 빠르게 도달했습니다.
### 3.3. MARWIL 하이퍼파라미터(Learning Rate) 비교
![[Pasted image 20251207195918.png]]
* **Case A (`15ebd`):** `lr=1e-4` (분홍색)
  ```
  .training(
        train_batch_size_per_learner=4096,
        # [MARWIL 핵심 파라미터]
        beta=1.0,
        lr=1e-4,
        num_epochs=50,
    )
  ```
* **Case B (`9b3c5`):** `lr=5e-5` (보라색)
  ```
  .training(
        train_batch_size_per_learner=4096,
        beta=1.0,
        lr=5e-5,
        num_epochs=100,
        vf_coeff=1.0,
    )
  ```
* **분석:** 학습률이 더 높은 `1e-4` 설정에서 초기 학습 속도가 월등히 빨랐으며, 최종 성능도 더 우수하게 나타났습니다. `5e-5` 설정(보라색)은 학습은 잘 진행되었으나 수렴 속도가 상대적으로 느렸습니다.
## 4. 종합 결론 및 고찰
1.  **데이터 양의 중요성:** 오프라인 강화학습에서 데이터의 양은 성능을 결정짓는 가장 중요한 요소였습니다. 50 에피소드로는 BC조차 제대로 된 성능을 내지 못했으나, 500 에피소드에서는 Expert에 준하는 성능을 보였습니다.
2.  **MARWIL의 우수성:** 전문가 수준의 데이터(Expert Data)가 확보된 상황에서는, 단순 모방(BC)보다는 이점 기반의 가중치를 사용하는 **MARWIL 알고리즘이 학습 속도와 최종 성능 면에서 가장 효율적**이었습니다. (그래프 상 분홍색 라인 `15ebd`가 Best Model)
3.  **CQL의 한계:** 데이터가 부족한 상황(50 Ep)에서의 CQL 적용은 학습 실패로 이어졌습니다. CQL을 사용하기 위해서는 더 방대한 데이터셋이 필요함을 시사합니다.
**최종 권장 모델:**
본 실험 결과에 따라, 500 에피소드 이상의 데이터를 사용하여 **MARWIL 알고리즘 (beta=1.0, lr=1e-4)**으로 학습하는 것이 가장 효율적인 전략으로 판단됩니다.
