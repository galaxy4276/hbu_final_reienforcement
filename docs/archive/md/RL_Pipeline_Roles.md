# 강화학습 파이프라인 역할 구성

이 문서는 `HalfCheetah-v5` 환경을 위한 강화학습(RL) 파이프라인에서 사용되는 세 가지 Python 스크립트의 역할과 기능을 설명합니다.

## 개요
파이프라인은 다음 세 가지 주요 단계로 구성됩니다.
1.  **전문가 정책 학습 (Training an Expert)**: 온라인 RL(PPO)을 사용하여 고성능 정책을 학습합니다.
2.  **데이터 수집 및 기록 (Data Collection)**: 학습된 전문가 정책을 사용하여 경험 데이터셋을 생성하고 저장합니다.
3.  **오프라인 학습 (Offline Training)**: 저장된 데이터셋만을 사용하여 새로운 정책을 학습합니다 (오프라인 RL / 행동 복제).

---

## 1. `orl_1_Training_an_expert_policy.py`
**역할: 전문가 정책 학습 (Online RL)**

*   **알고리즘**: PPO (Proximal Policy Optimization).
*   **목표**: `HalfCheetah-v5` 환경에서 높은 성능(전문가 수준)을 달성하도록 모델을 처음부터 학습시킵니다.
*   **주요 기능**:
    *   PPO 하이퍼파라미터 설정 (학습률 스케줄, 배치 크기 등).
    *   관측값 정규화를 위해 `MeanStdFilter` 사용.
    *   평가 에피소드 보상이 **3000**점(또는 설정된 목표)을 초과할 때까지 학습.
    *   **출력**: 다음 단계에서 사용할 최고 성능의 모델 체크포인트를 저장합니다.

## 2. `orl_2_Record_expert_data_to_local_disk.py`
**역할: 데이터 생성 및 기록**

*   **목표**: 학습된 전문가 정책을 실행하여 "전문가 시연(demonstrations)" 데이터셋을 생성합니다.
*   **주요 기능**:
    *   `orl_1`에서 생성된 **최고 성능 체크포인트**를 로드합니다.
    *   전문가 정책을 사용하여 환경을 추론 모드(학습 없음)로 실행합니다.
    *   관측값(observations), 행동(actions), 보상(rewards)을 포함한 전체 에피소드를 수집합니다.
    *   **출력**: 경험 데이터를 `halfcheetah_expert_ppo` 디렉토리 아래에 **Parquet 형식**으로 로컬 디스크에 저장합니다. 이 데이터는 오프라인 학습을 위한 "정답지" 또는 "전문가 행동" 역할을 합니다.

## 3. `orl_3_Training_on_previously_saved_experiences.py`
**역할: 오프라인 강화학습 (Behavior Cloning)**

*   **알고리즘**: BC (Behavior Cloning, 행동 복제).
*   **목표**: 학습 도중 환경과 상호작용하지 않고, *오직* 사전 기록된 데이터만을 사용하여 전문가의 행동을 모방하는 새로운 정책을 학습합니다.
*   **주요 기능**:
    *   `orl_2`에서 생성된 오프라인 데이터셋을 로드합니다.
    *   행동 복제(BC) 알고리즘을 구성합니다.
    *   데이터셋에 있는 전문가의 행동과 모델의 행동 간 차이를 최소화하도록 새로운 모델을 학습시킵니다.
    *   주기적으로 실제 환경에서 새 모델을 평가하여 성능을 검증합니다.
    *   **출력**: 오프라인 데이터만으로 학습되어 전문가와 유사한 성능을 낼 것으로 기대되는 정책.
